Tab Cloak

How your tab will appear in history, on filtering extensions, and more.

about:blank

Open the site inside a new about:blank tab whose title and page match the disguise above, so this site never appears in history or in a filter's report.



Auto about:blank

On every visit, move the site into an about:blank tab and send this tab to Google Classroom. Meant for filters that report the address you opened. Off by default.



Confirm Leave

This setting is useful if teachers are trying to close your tab. When the tab is closed, it will show an "Are you sure you want to leave this site?" popup to prevent tab closing.



Panic Key

One key press hides what you were doing. The current tab is replaced by the destination below, and the page stays black until that site has finished loading, so the proxy is never shown. Press Esc on the decoy to come back.

Off by default. Keys like \ and Escape cannot be typed by accident.

Session Traces

Graip remembers your open tabs for this window only, so a reload does not lose them. Clear them here (panicking already does this) and the address bar is reset too.




Backup & Restore

Your settings live only in this browser. Save them to a file here and you can move them to another device, another deployment, or back again after clearing site data.

The file holds preferences only — theme, cloak and panic options, Wisp route, search engine, game store and logging. It never contains your tabs, your history or the debug log.

Restore from a file

Only the settings inside the file are changed. Everything else stays as it is, so a two-line file is a valid partial restore.
